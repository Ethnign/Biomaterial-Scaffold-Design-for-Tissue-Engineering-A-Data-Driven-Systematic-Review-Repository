# results/figures/

Gephi-rendered network images for the two content axes discussed in the manuscript's text but not shown as main-text figures (Fabrication Strategy, Engineering Property). These are provided for convenience; they are not numbered manuscript figures. The underlying complete network data for all five axes is in `results/networks/*.gexf`.

`superseded_matplotlib/` holds the original matplotlib-generated network renders for all five axes, replaced in the manuscript by the Gephi renders in `manuscript/figures/` and here. Kept for provenance, not for reuse.
